# Agent Team Workbench 文档资料

该目录集中保存 Agent 开发团队工作台的架构、Web 协议和原型参考资料。

## 目录结构

- architecture/
  - runtime-agnostic-agent-team-workbench-system-design.docx：可替换 Runtime 的总体系统设计。
- protocol/
  - agent-team-dashboard-web-protocol-go.docx：基于原型整理的 Go Web 协议对接规范。
- references/
  - agent-team-dashboard-prototype.zip：用户提供的完整原型包。
  - product-brief.md：原型产品简报。
  - confirmed-ia.json：原型信息架构与视觉方向。
  - wireframe.jpg：原型线框图。

归档采用复制方式，原始文件仍保留在原位置。
