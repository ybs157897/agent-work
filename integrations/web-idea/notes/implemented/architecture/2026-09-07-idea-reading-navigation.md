# IDEA 习惯的轻量阅读工作台

Status: implemented

## 决策与理由

AI 生成代码后的主路径是找文件、读实现、查定义/用法，再回到原处。保留 IDEA 的项目树、编辑器标签、面包屑和键盘操作；只呈现已实现的动作。快速文件定位由 Gateway 在 Workspace Root 内按路径搜索，不为此启动语言服务或在浏览器预读工程源码。

标签只保留路径与位置，编辑区复用一个 Monaco model；关闭/切换 Java 文档时发送 didClose。最多保留 30 个标签/最近文件与有界历史，避免阅读越久常驻 buffer 越多。文件切换必须等待当前改动保存成功；失败保留原文件并显示可重试错误。加载过程中不可编辑旧 buffer。

## 放弃了什么

不复制完整 IDE 菜单、运行/调试和重构能力，不引入第二套语言服务，不预建全量内容索引。完整 IDEA 皮肤一致性服从真实功能、可访问性与阅读效率。字体使用本地系统回退，避免阅读依赖远端字体请求。

## 验收

真实 Gateway + 浏览器验证快速打开深层文件、标签切换、定位行、光标返回、目录揭示、Markdown 阅读、保存后切换与关闭；Java 语义能力另用真实 jdtls 验证。记录 model 数量和请求行为，不把构建通过或单次内存读数写成优于 IDEA 的性能结论。

## 收口证据

实现与验收结果见 [阅读工作台](../../../docs/architecture/reading-workspace.md)。三个阶段基线已保存并快进到 main 的 `2bbfb37`；本轮优化从该点在 `codex/idea-navigation-reading` 工作区完成，尚未再次合入 main。
