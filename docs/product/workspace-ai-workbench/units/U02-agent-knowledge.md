# U02 工作空间内的 Agent 知识隔离

状态：已完成；功能完成：`[x]`。更新：2026-09-09。

## 目标与范围

知识归属明确为“工作空间 → Agent → 知识内容”，不同工作空间可保存不同领域和性质的知识。打开 Agent 知识时直接使用全局当前空间，不再出现独立空间切换入口。

本单元负责知识列表、读取、检索、写入、版本/关系、缓存和 AI 知识工具的空间边界。保留当前空间内已有的私有/共享可见性；不自动跨空间复制、聚合或共享知识。Agent 角色模板不等于已经跨空间共享的业务知识。

## 输入、输出与依赖

输入：U01 的当前空间、受信任的 Agent/Run 归属及查询/写入请求。
输出：只在该空间授权范围内可读写的确定版本知识及来源，供 U03/U04 使用。
依赖：U01；切换入口由 U01 负责。旧数据有明确空间归属则保留；归属不明的数据先列明，不猜测分配。
