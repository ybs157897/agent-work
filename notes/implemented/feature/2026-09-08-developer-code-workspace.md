# 开发 Agent 代码阅读工作台

Status: implemented

## 决策与理由

采用完整源码快照 + 独立 Gateway + 同源受限 iframe，复用现有知识画布的布局和对话。快照包含原始 web-idea 工作树的未提交实现，并记录逐文件摘要。阅读目录沿用工作台已有执行上下文和 HostRegistry 权威链。Chat 仍使用 Agent 自身运行时配置；代码画布不选择或替换模型。

## 放弃了什么

不使用固定本机路径指向旁边的项目，避免构建依赖不可追溯的工作树。不只用角色隐藏按钮；所有工作区和语义请求都经过后端固定范围。不把两个不同 React 版本和 Monaco 状态整体塞进聊天页面。阅读会话不创造第二套任务状态机，不抢占 Agent checkout 锁。

## 复活条件

当远程 Runner 提供文件/语义阅读协议时，为相同会话接口接入 Host transport；在此之前远程目录明确不可用。当用户明确要求协同编辑时，先定义缓冲区、并发写入与冲突恢复合同，再开放集成写入口。

## 联合验收

Java 阅读、权限拒绝、撤销后长连接关闭、pagehide 进程与索引回收、明暗与窄屏均已验证。独立预览的右侧 Chat 使用 Mock，真实模型聊天没有完成验收。Maven 的空输出目录边界如实记录在验收报告；未扩展到操作系统沙箱。详见 [验收记录](../../../docs/product/developer-code-workspace-acceptance.md)。
