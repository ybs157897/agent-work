# 知识阅读与统一工作台风格

状态：实现与隔离预览验收完成。日期：2026-09-08。见[验收记录](knowledge-reading-acceptance.md)。

## 用户确认与范围

知识库改造采用紧凑列表、宽正文、服务端全文检索、可导航来源/关联、固定版本深链和带条目进入统一聊天。继续由内置知识管理员承担整理和写入；知识库页面维持只读。图数据库、外部 RAG 平台和语义向量检索不在本次范围。

工作台整体以现有生产 Agent 正文的 LanguageGUI 阅读风格为基准：统一无衬线字体、中性明暗表面、正文层级、克制蓝色强调、边框和控件间距。删除水墨纹理、山水装饰、书法字体、印章式品牌装饰。保持现有 Markdown、代码、工具过程和内容块能力。

左侧主菜单固定显示图标和文字；删除折叠状态、鼠标悬浮展开、汉堡菜单和自动收起。侧栏独立滚动，页面内容占剩余空间；窄窗口仍保留可见菜单，通过紧凑宽度和内容堆叠适配。

## 知识库交互契约

- 全库搜索通过现有 SQLite/FTS5 读取投影和访问过滤实现，覆盖正文与已加载分页之外的条目；有效知识、权限、范围、版本仍以 SQLite 为唯一权威。
- 阅读采用类型导航、紧凑结果列表和宽正文；页内目录来自实际 Markdown 标题。较窄内容区采用列表/正文切换，保留返回路径。
- URL 表达查询、类型、条目和具体版本，刷新/前进/后退可以恢复；无效或不可访问条目展示可恢复错误。
- 来源展示名称、摘录和实际核验状态。支持的任务、Run、文档 URL 提供类型化安全只读跳转；不支持的 locator 保留可复制信息，不构造假链接。
- 关联展示有权限读取的目标知识标题和方向；点击在知识阅读上下文中导航。历史正文与当前有效关系明确区分。
- 版本选择标明历史/当前，提供真实内容差异；不编造变更原因或测试已通过的结论。
- 「与知识管理员对话」进入既有普通 Chat，携带条目/版本引用形成可编辑草稿；不自动发送、不自动写知识。提供返回知识入口。
- 原 V2 的「唯一跨页动作」更新为「唯一问答/写入入口是统一聊天；允许有权限的只读条目、来源与引用导航」。

## 验收

1. 用超过 200 条、仅正文命中、中文词组的样本验证搜索；废止/跨工作区/private 知识不得泄漏。
2. 列表、详情、目录、关联、来源、版本、深链刷新与返回均走真实 UI，并检查对应 API/SQLite 结果。
3. 进入管理员聊天后只出现草稿，未发送前不创建 Run；当前知识和版本引用可回读。
4. 总览、智能体、模型、任务、聊天、知识、设置等主要页面无水墨装饰，正文和外壳明暗主题一致；侧栏始终可见且无收起控制。
5. 前端 tsc -b、test、lint、build；后端 build/vet 与触面 race；记录实际 UI 截图及剩余限制。
