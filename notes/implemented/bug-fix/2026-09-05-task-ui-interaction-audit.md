# 任务工作台交互评审修复

Status: implemented

## 决策与理由

沿用总任务看板、Worker 输入和最终输出直接展开、根任务一次验收。修复本轮真实页面发现的点击穿透、低高度裁切、结果请求错误被当作加载中、筛选后任务摘要失真、显示编号无法搜索，并统一待验收状态与可操作条件。

弹层层级同时管理遮罩、焦点和背景不可交互；关闭表单保留未提交草稿，成功后清除。任务数据完整加载后才进行根任务可见性筛选，参与者始终从不受筛选影响的集合推导。任务可验收性只读投影既有控制面条件，GET 不生成或修改验证证据，最终写命令继续执行完整校验。

## 放弃了什么

- 只抬高弹窗本体 z-index：无法阻止遮罩以下背景按钮接收点击。
- 把网络错误显示成空结果或永久加载：用户必须看到失败和当前 Agent 的重试入口。
- 从已筛选列表统计参与者：筛选应影响可见总任务，不得改写任务内部摘要。
- 新增持久化任务状态：待验收是领域状态和控制面条件的只读投影。
- 恢复子任务页面或工具/思考时间线：本轮遵循已确认的简化任务追踪体验。

## 验证边界

按触面执行前端类型、Lint、测试与构建；后端执行相关 HTTP/应用层测试。浏览器在 SQLite 在线备份副本上验证鼠标与键盘弹层、错误恢复、分页筛选、显示编号搜索及窄/矮窗口。正式业务数据不参与写入测试。

## 验证结果（2026-09-05）

- 前端 `pnpm test`：102 文件、839 条测试通过；最终颜色/窄屏对齐微调后额外通过 6 条看板渲染与 token 检查。`pnpm build`（包含 `tsc -b`）与 `pnpm lint` 通过。
- 后端 `go build ./...`、`go vet ./...` 通过；`go test -race -count=1 ./internal/httpapi` 通过（214.376s）；应用层 ReviewAvailability 的 6 条 race 测试通过（23.239s）。
- 看板显示短编号搜索可命中根任务；中优筛选后已完成任务仍为 8 个子任务、5 个去重参与者。SSE cursor resync 也通过统一 hydrate 入口补齐分页，另有防回归断言。
- 375px 列表保留编号、标题、头像、优先级，页面 scrollWidth=375；详情无横向溢出。1280×320 打回 Modal 的取消/提交均在视口内，正文独立滚动。
- 嵌套弹层背景不可交互，Escape 只关闭最上层，随后恢复焦点和滚动；关闭再打开保留打回草稿。浏览器 Back 保留短编号搜索与列表视图。
- 单独屏蔽 Nova 的 events 请求可得到明确失败与重试，Pixel/Forge 正常；取消屏蔽后局部重试恢复最终正文。重试按钮卸载导致焦点落 body 时，Escape 仍可正常退出。
- 详情只显示一个“待验收”状态；徽章文字实测对比度 4.73:1，验收按钮白字约 5.18:1。任务完成后不再显示验收按钮或“尚未到验收阶段”提示。
- 在 `/tmp/atw-ui-fixes.J55QhX/workbench.db` 的在线备份副本上点击一次“总任务验收通过”：根任务由 v13→v14 completed，3 个子任务由 v6→v7 completed，Coordinator v12→v13 completed，Goal 与当前 Todo 均 completed；页面自动退出详情并归入完成区。未改变正式数据库。
- 旧 Nova 子任务深链实际重定向到根任务，只展示根任务状态及 Worker 输入/最终输出。

## 交付边界

实现与上述验证在 `codex/simplify-task-peek` 隔离 worktree 完成；经用户授权后合并到本地 main，主树无关改动保留，不推送远端。预览使用验收前的新在线备份 `/tmp/atw-ui-preview-final.YjfG7Q/workbench.db`，外部模型执行禁用，因此本轮不声明验证了模型调用或新任务自动执行。既有 SSR `useLayoutEffect` 和 Vite chunk-size 警告未掩盖，未扩展到无关优化。
