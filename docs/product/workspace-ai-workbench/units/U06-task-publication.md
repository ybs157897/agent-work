# U06 确认结果形成任务与发布

状态：已完成；功能完成：`[x]`。更新：2026-09-09。

## 目标与范围

将当前空间已确认的需求、异常处理与验收条件形成可审阅草案，用户明确发布后进入现有 Task/Run 流程。任务可追溯到本次资料及确认版本。

本单元负责草案与发布衔接，复用已有 WorkItem、开发上下文与 Coordinator。工作空间由 U01 提供，不让用户在发布页重新选择空间，不新建调度器。

## 输入、输出与依赖

输入：U01 当前空间/代码资源，U05 有效确认与分析版本，用户发布动作。
输出：当前空间下的 Task 及来源/确认版本引用，或可恢复的发布失败。
依赖：U05；项目代码基线和引用的变化在发布前重新核对。

## 开工记录

- Owner：backend 应用/数据/API，architecture 基线及真实Git测试，frontend web，root 验收/整合。分支 `codex/u06-task-publication`。
- 已有实现：WorkItem 发布、项目绑定及不确定发布结果重放已有局部验证，尚未覆盖新全局空间与确认合同。
- 初步触面：任务创建接口与应用服务、开发上下文、需求草案发布 store。准确文件范围恢复开发时填写，共享文件指定唯一 owner。
