# P1 用绝对 path 表单开工作区

Status: implemented

## 决策与理由

P1 演示入口在 Web 上提供 Gateway URL、dev token、本机绝对 `root` 表单，由浏览器 `POST /api/v1/workspaces`。这与「本地单用户 / 调用方已对 root 有权」的信任假设一致，且不依赖宿主注入，便于独立跑通只读浏览出口。

## 放弃了什么

- **仅宿主深链注入 workspaceId**：嵌入场景正确，但会阻塞本仓库独立演示。
- **Web 直接读本地目录（File System Access API）**：绕过 Gateway，破坏 root jail 与后续 LSP 同一信任边界。

## 复活条件

宿主嵌入落地且默认不再本地演示 → 表单可降为 `?dev=1` 调试入口，主路径改为宿主签发的 workspace 会话。
