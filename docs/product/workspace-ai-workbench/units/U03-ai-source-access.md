# U03 AI 读取资料与原附件

状态：已完成；功能完成：`[x]`。更新：2026-09-09。

## 目标与范围

把当前对话材料、原始 Word/PPT/Markdown 附件、已关联项目代码及当前空间知识交给 AI。AI 按需读取后理解和整理。工作台负责保管原件、访问范围、版本和读取记录；上传与已读必须区分。

本单元只交付 AI 能实际访问资料的能力，不实现需求业务判断、问答或产品确认。文件读取工具可以做必要的格式访问，但不能用固定摘要替代 AI 阅读，也不能把原文件 base64 当作模型已读的证据。用户已明确本机 Runtime 的交付方式：工作台保存原件，服务端校验 source_refs 的 Workspace/Chat/Agent 归属，再把经核验的本机路径和资料说明交给既有 Chat Run；Agent 使用自身文件/命令工具读取。不建设 provider 原生附件上传协议或专用模型调用链，不把缺少 input_file 协议当作本机 Runtime 无法读文件。浏览器仍只拿 opaque source_id；实际路径仅在受信运行时上下文中解析。

## 输入、输出与依赖

输入：U01 当前空间及代码资源，用户附件/对话，U02 授权知识接口。
输出：原件引用及摘要、Run 内经核验的文件路径、AI 实际读取记录、可核对的内容定位与版本、未读取/失败/部分读取状态，供 U04 使用。已保存、已交给 Agent、已读取分别显示。
依赖：U01、U02 的知识合同。部分输入不可读时保留其他资料，不伪称全部读完。
