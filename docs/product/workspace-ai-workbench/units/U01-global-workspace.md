# U01 唯一全局工作空间与状态恢复

状态：已完成；功能完成：`[x]`。更新：2026-09-09。

## 目标与范围

一个工作空间对应一个本机项目目录，全应用只有一个打开/创建/切换入口，页面共用当前空间。进入新空间内容独立；A → B → A 恢复 A 的原内容。覆盖对话、任务、附件、草案、知识页面、代码上下文和深链接。

本单元负责空间归属、全局切换、路由及异步状态隔离，并处理之前新增的局部项目选择入口。固定项目根由空间持有，分支变化不提供第二个页面级项目选择。新空间一次性复制源空间 Agent 配置为独立实例，使用现有配置真相链落盘。业务知识访问逻辑由 U02 负责，附件读取由 U03 负责。

## 输入、输出与依赖

输入：已登记工作空间及其资源配置、原空间保存状态。
输出：唯一当前 `workspace_id`、切换生命周期、内容恢复规则；各页和后续单元使用同一合同。
依赖：无；U02–U06 消费该合同。切换中的迟到结果必须保留原空间归属或丢弃，不能覆盖当前空间。
