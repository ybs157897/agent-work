# U04 需求分析与一次一问

状态：已完成；功能完成：`[x]`。更新：2026-09-09。

## 目标与范围

AI 根据已读资料整理需求、正常场景、异常场景、材料冲突及影响，并给出有来源的建议。当前交互只显示一个可回答的问题，支持选择和补充；其余问题保留为待办，不一次全部抛出。

本单元负责分析结果与问答过程。U03 负责读取，U05 负责产品确认与变更状态，U06 负责发布任务；分析回复本身不等于执行或产品批准。

## 输入、输出与依赖

输入：U02/U03 的授权已读资料和覆盖缺口、用户目标与已有回答。
输出：带来源的分析版本、一个当前问题、未答待办及回答记录，供 U05 使用。
依赖：U01–U03。已答内容不重复追问；遇到新的相关冲突时说明重问原因。
