# Agent Team Workbench 文档资料

该目录集中保存 Agent 开发团队工作台的架构、Web 协议和原型参考资料。

## 最终目标

- end-goal.md：**最终目标文档**（end goal）——产品收口愿景：正交 agent 配置、agent 自管理会话（前缀缓存契约）、lead/worker 编排角色层、知识层；含现状对账与 M1–M4 分期路线。

## 角色章程（agent 灵魂，粘贴即 system prompt）

- product-agent-charter.md：**产品 Agent 章程**——澄清（需求决策树访谈：前沿轮问 / 事实决策分离 / 八维问全）→ 立法（法典化：应当·不得·可以 / 版本链 / ID 永不复用）→ 交付（条目引用移交开发）三段循环 + 全局红线自检；附录含提问 / 共识摘要 / 条目 / 树况四套模板。

## 目录结构

- architecture/
  - runtime-agnostic-agent-team-workbench-system-design.docx：可替换 Runtime 的总体系统设计。
- protocol/
  - agent-team-dashboard-web-protocol-go.docx：基于原型整理的 Go Web 协议对接规范。
- references/
  - agent-team-dashboard-prototype.zip：用户提供的完整原型包。
  - product-brief.md：原型产品简报。
  - confirmed-ia.json：原型信息架构与视觉方向。
  - wireframe.jpg：原型线框图。

归档采用复制方式，原始文件仍保留在原位置。
