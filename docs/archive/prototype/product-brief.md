# Agent Team Dashboard — 产品简报

## 产品定位
面向 AI 工程师与产品团队的多智能体协作监控平台。核心价值：让 Agent 的运行状态、任务分配与协作流程完全可见、可控、可调度。桌面端 SaaS Dashboard。

## 目标用户
- AI 工程师：日常监控多个 Agent 运行状态，排查错误，调整任务分配
- 产品团队：跟踪 AI 驱动的任务执行进展，管理工作流优先级

## 核心功能

### 1. 总览 Dashboard
- 欢迎头部 + 关键统计卡（活跃Agent数 / 运行中任务 / 今日完成）
- Agent 状态快速预览（横向滚动 mini 卡片）
- 任务进度快照（各看板列计数）
- 实时日志流（带时间戳的活动记录）

### 2. 智能体团队
- Agent 卡片网格（有大小节奏变化，非均等网格）
- 每张卡片：头像 + 名称 + 角色标签 + 状态指示器 + 当前任务摘要 + 进度条
- 点击卡片滑出右侧详情面板（技能列表 / 任务历史 / 状态切换）
- 支持添加新 Agent

### 3. 任务看板
- Kanban 四列：待办 / 进行中 / 完成 / 阻塞
- 任务卡：标题 + Agent 分配标签 + 优先级标记 + 截止日期
- 视图切换（看板 / 列表）
- 筛选（优先级 / 指派人）

### 4. 日志 & 设置（导航占位）

## 信息架构
- 三屏结构，左侧 60px 图标导航贯穿全局
- 布局比例：侧边栏 60px | 主内容区 fluid | 详情面板 280px（按需滑入）
- 顶部栏：面包屑 + 用户头像

## 视觉风格
轻盈亲和与空间呼吸感融合——白色/浅灰基底，面板间微妙色温差异，蓝绿点缀色，柔和卡片阴影。整体气质像一个整洁的指挥舱，克制而有层次。

## 平台
Desktop（桌面端 Web）
