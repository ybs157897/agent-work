# U05 产品确认记录与变更复核

状态：已完成；功能完成：`[x]`。更新：2026-09-09。

## 目标与范围

开发与产品在工作台外沟通后，回填确认结果及依据。后续需求、文档、代码或知识发生变化，核对影响并重开相关结论；无关确认和历史记录保留。

本单元负责确认、变更与历史，不要求产品本人进入工作台，也不把模型建议、用户普通回答或模拟确认材料自动升级为产品批准。

## 输入、输出与依赖

输入：U04 分析版本/待确认项，开发明确回填，U03 来源变化。
输出：带版本/依据的确认记录、受影响待复核项和有效确认范围，供 U06 发布校验。
依赖：U04。无法可靠判定影响时显示待核对及原因，不默认为仍然有效。
